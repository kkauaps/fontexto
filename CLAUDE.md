## Authorship (mandatory)

The only author and contributor of this repository is **Pablo Kauã Pereira Silva** (@kkauaps).

- Commit as `Pablo Kauã Pereira Silva <kauapsilva03@gmail.com>`, as both author and committer.
  Before the first commit in a new clone, run:
  `git config user.name "Pablo Kauã Pereira Silva" && git config user.email "kauapsilva03@gmail.com"`
- Never add `Co-Authored-By`, `Co-authored-by`, `Claude-Session` or any other trailer that names an AI

  can add co-author lines).
- Never push commits authored by anyone else to any branch of this repository.
